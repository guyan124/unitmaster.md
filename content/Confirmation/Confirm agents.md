### Confirm Agents

***Step One***
```
Go to the confirm menu then click on the confirm agents sub-menu. It gives a list of agents pending approval. A user then clicks on the blue confirm button.
```
![](/images/con.png)
***Step two***
```
A pop-up page appears with the agent’s details. The user clicks the confirm button at the bottom of the page to confirm the agent.
```

<img src="/images/tables.png" alt="Agents sidebar" class="img-small-B"  width= "400px"/>


```
A confirmation then appears at the top of the page confirming the transaction is complete.
```
