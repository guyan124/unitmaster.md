 ### Receipting

 ***Step One***
```
Go to Transactions menu then click on the Receipting sub-menu. A user can access members’ information in order to send a receipt for a transaction. A user can search for a member using the search button on the top right of the page.

 ```
![](/images/trans1.png)
  

  ***Step Two***
  
  ```
By clicking on the blue accounts button, a user can then key in the details of the particular transaction that needs to be receipted.

 ```
 ![](/images/tran2.png)

 ***Step Three***
 ```
A user can then choose which fund the transaction belongs to by clicking the green purchase button.
 ```


![](/images/tran.png)

 ***Step Four***
 ```
A user can then key in the relevant details for the transaction and the click the submit button to generate a receipt for that particular transaction.

```


![](/images/tran4.png)


 ***Step Five***
 ```
The transaction is then posted successfully.
 ```
