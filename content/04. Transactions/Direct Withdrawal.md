Description: Overview

***Step One***
```
Go to the Transactions menu then click on the Direct Withdrawal sub-menu. This allows a user to make a direct withdrawal from a member’s account.
```
***Step Two***
```
The user searches for a member using the search button on the top left then selects the member’s details.
```
![](/images/trans8.png)

![](/images/trans9.png)

 ***Step Four***
```
The user clicks on the green withdraw button to complete the transaction.
```
