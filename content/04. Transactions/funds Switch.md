***Step One***
```
Go to Transactions menu then click on the Fund Switch sub-menu.
```
***Step Two***
```
A user can initiate a switch from one fund to another. Start by searching for the member using the search button on the top left side, then selecting the member’s details from the dropdown button on the top right side.
```

![](/images/cs.png)


***Step Three***
```
The user the selects the transaction date and the account funds are moving from to account funds are moving to.
 ```
The user can also create a new account for the member by clicking the new account button.
 
 ![](/images/css.png)

The pop-up below appears and the user can populate the field with the required details.

![](/images/cl.png)

***Step Four***
 ```
The user then selects the switch type, i.e. whether to move all funds or partial funds. A reason for the switch is also required and a further narrative to support the reason can be typed.
 ```
![](/images/sum.png)

   ***Step Five***
```
The user then clicks the submit button and a confirmation window appears. Once the user confirms the switch, then the transaction is complete.
```
