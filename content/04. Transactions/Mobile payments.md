### 	Mobile Payments

***Step One***
 ```
Go to the Transactions menu then click on the Mobile Payments sub-menu.
 ```
***Step Two***
 ```
A user can generate a list of payments made through mobile money and also search for a mobile payment transaction using the search button on the top right side.
 ```
 8![](/images/con.png)

 The **Blue confirm button** is used to confirm if the details are correct. The **Red cancel button** is to delete the details on the mobile payment listing.
