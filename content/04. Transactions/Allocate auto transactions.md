Tittle: Allocate auto transactions
Description: Overview
---


***Step One***
 ```
Go to Transactions menu then click on the Allocate auto transactions sub-menu.
 ```
***Step Two***
 ```
A user can search for transactions pending receipting, using either the transaction number on the main search bar or member number on the search bar on the top right side.
```
![](/images/tran5.png)

***Step Three***
```
A user can then confirm a transaction of receipting clicking on the blue confirm button as well as confirm multiple transactions, by clicking the allocate multiple button; or cancel the transaction by clicking the orange cancel button.
```
![](/images/tran6.png)
