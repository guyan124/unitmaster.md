### Fund expense
```
 A user can set up fund expenses per fund on this module. Vat and excise controls on the expense can be set on the creation and updated on the update form respectively. Click on Add Expense to capture an expense. 
```
 ![](/images/fund4.png)

The buttons on the right side :

 
 The **View button** is used when you only want to see the details of something.It opens a page that displays all the information clearly so you can read and understand it, just like opening a book to read a page.
 
 It has a yellow background color.


The **Edit button** in the page  allows you to change or update existing information. When you click it, a form opens with the current data already filled in, and you can modify things like a command description or lesson content, then save the changes to update the system.

It has a blue background color.

The **Delete button** is used to remove an item completely. When clicked, it usually asks for confirmation to prevent mistakes, and once confirmed, the selected command, lesson, or topic is permanently deleted from the system.

It has a red background color

***Step one:***
 
 - Press the button **add expense**.
 
 ***Step two***

 - Fill the expense form and hit on submit to save the expense.
 
  ![](/images/expense.png)

  - The **Save button** means you want to keep and store the information you have entered 

  - The **Cancel button** means you do not want to continue with the changes you were making. In 
    clicking Cancel closes the form or takes you back to the previous page without saving anything, so all the changes you typed are discarded.
