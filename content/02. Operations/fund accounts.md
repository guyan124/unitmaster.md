###	Fund Accounts
```
This allows the user to view and add on to a list of fund valuation. A user can search for the valuation using the valuation date.
One can evaluate funds to know the money aspects.
```
 The blue **Valuation Statement** button provides more detailed information about the valuation statement, while the red button allows you to delete  the details in the valuation list.

![](/images/fcc.PNG)

On the right side youll see a button **Add evaluation**
It is a way to compute the value of scurity and also be able to find the **NAV** rate for clients and get a breakdown of expense and other account information .

![](/images/NAV.PNG)

After you fill all details you click the  blue button on the bottom-right **confirm valuation**.

![](/images/val.PNG)
