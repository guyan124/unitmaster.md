### communication templates
```
Communication templates are pre-designed, standardized formats for regular reports and notices sent to beneficiaries. They help ensure that all required information is delivered consistently, clearly, and on time. 

Communication templates can be updated from the Communication templates sub module in the Admin Menu. Click on edit to update the body.
```
![](/images/AT.png)




The **Edit button** lets authorized users update the details of a fund or security. It ensures that all records remain accurate and current. It has the  blue color. A user can edit and click on save to update the communication template.


The **Delete button** allows users to permanently remove a fund or security entry that is no longer needed. Usually, it asks for confirmation to prevent accidental deletion. It has the red color.


The **View button** displays all the details of a fund or security without allowing any changes. It provides a safe way to review information for auditing or reference purposes. It has the yellow color.


![](/images/view.png)

On the right side theres a  button **Add templete** where you add a new design to the emails so you can send it to the clients.
