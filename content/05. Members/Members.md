###  Members
In this page it shows a list of all confirmed members. It shows the single member , single member and joint member.

![](/images/mem3.png)

On the right side of the page there are buttons:

 **View** ( green Eye icon)
This icon is used to view details of a record. When clicked, it opens the information in read-only mode so you can see everything without changing anything.

 **Edit** ( red Pencil icon)
This icon allows you to edit or update existing information. Clicking it opens a form where you can change and save new details.

 **Document** (green File icon)
This icon usually means view or generate a document, such as a report, profile, or printable file related to the record.

 **Message / Email** (Envelope icon)
This icon is used to send a message or email related to the record, such as notifications or communication.

**Delete** (Recycle/Bin icon)
This icon is used to delete or remove the record from the system. Most systems may ask for confirmation before deleting.
