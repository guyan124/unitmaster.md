> ### Step One
```
Go to Maintenance menu then click on the Interest Rates sub-menu.
```
<img src="/images/int.png" alt="Agents sidebar" class="img-small" />

> ### Step Two
```
A user can generate a list of confirmed and approved interest rates using specific date then click on the filter button or use the upload interest rate button. 
```
![](/images/ratee.png)



 The **Approved Interest** button shows that an interest rate has been reviewed and officially accepted for use in the system. The **Edit button** allows authorized users to modify the interest rate details, such as the percentage or validity period, if updates are needed.The **Delete button** permanently removes an interest rate from the system when it is no longer required, usually after confirmation.

> ### Step Three
```
Once you click the upload Interest rate button select the fund and the file to upload then click the green upload button. 
```
